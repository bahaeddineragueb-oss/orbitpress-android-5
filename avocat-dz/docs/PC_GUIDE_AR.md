# دليل Logiciel PC — مكتبي - maktabi (Windows)

## نظرة سريعة
مكتبي - maktabi الآن **logiciel PC حقيقي** لـ Windows 10/11:
- تثبيت بضغطة (Setup .exe) أو نسخة محمولة Portable بدون تثبيت
- يعمل **Offline 100%** — لا يحتاج انترنت بعد التثبيت
- بياناتك تُحفظ على جهازك: `%APPDATA%/مكتبي - maktabi/maktabi-data.json` + مجلد الوثائق `Documents/مكتبي - maktabi/`
- نفس الواجهة العصرية (RTL) مع قائمة سطح مكتب علوية وقصارات لوحة المفاتيح

---

## التحميل

### الخيار 1: المثبت (موصى به)
- الملف: `مكتبي - maktabi-Setup-1.0.0.exe` (~85MB)
- حمّله من صفحة **/download** داخل التطبيق أو من **Releases** على GitHub
- شغّله → اختر مجلد التثبيت → أنشئ اختصار سطح المكتب

### الخيار 2: Portable
- الملف: `مكتبي - maktabi-Portable-1.0.0.exe` (~80MB)
- لا يحتاج تثبيت — ضعه على USB وشغّله مباشرة في المحكمة أو أي حاسوب
- مثالي للمحامين المتنقلين

> **SmartScreen:** أول مرة قد يظهر تحذير Windows SmartScreen لأن التطبيق جديد — اضغط `More info` → `Run anyway`. سيتم إضافة توقيع EV في الإصدار القادم.

---

## التشغيل الأول

1. افتح **مكتبي - maktabi** من سطح المكتب
2. ستظهر لوحة التحكم — أضف أول عميل وقضية من `العملاء → + عميل جديد`
3. البيانات تُحفظ تلقائياً على جهازك (لا حاجة لحفظ يدوي)

---

## أين تُحفظ البيانات؟

```
Windows:
  البيانات: C:\Users\<YOU>\AppData\Roaming\maktabi\maktabi-data.json
  الوثائق: C:\Users\<YOU>\Documents\مكتبي - maktabi\
  النسخ الاحتياطي: يمكنك تصدير JSON من الإعدادات → نسخ احتياطي
```

- كل شيء JSON مشفّر محلياً — لا يُرسل لأي خادم
- يمكنك نسخ `maktabi-data.json` يدوياً كنسخة احتياطية

---

## النسخ الاحتياطي والاستعادة (مهم!)

### داخل التطبيق (موصى به)
- `الإعدادات → نسخ احتياطي → إنشاء نسخة الآن` → اختر مكان الحفظ
- للاستعادة: `استيراد نسخة` → اختر ملف JSON → سيتم إعادة التشغيل

### يدوياً
- انسخ الملف `maktabi-data.json` إلى USB أو Google Drive
- للاستعادة: استبدل الملف في `%APPDATA%/maktabi/` ثم أعد تشغيل التطبيق

| `Ctrl+1` | لوحة التحكم |

## الطباعة و PDF

- كل الصفحات قابلة للطباعة: `Ctrl+P` أو زر `طباعة/PDF`
- النماذج: بعد تعبئة الحقول → `توليد` → `طباعة/PDF` → احفظ كـ PDF أو اطبع مباشرة
- الوثائق: `معاينة` → `طباعة`

- قريباً: تحديث تلقائي داخل التطبيق

## البناء من المصدر (للمطورين)

### متطلبات
- Node.js 18+ (حمّله من nodejs.org)
- Windows 10/11 أو Linux/Mac للبناء

### الأوامر

```bash
# 1. فك الضغط و التثبيت
npm install

# 2. التشغيل للتطوير (يفتح الويب + Electron معاً)
npm run dev:pc
# - الويب: http://localhost:3000
# - الـ PC سيفتح تلقائياً

# 3. بناء المثبت (Windows)
npm run dist:win
# الناتج: dist/مكتبي - maktabi-Setup-1.0.0.exe

# 4. بناء المحمولة
npm run dist:portable
# الناتج: dist/مكتبي - maktabi-Portable-1.0.0.exe

# 5. بناء للويب فقط (للـ Vercel)
npm run build:web
```

### هيكل Electron

```
electron/
  main.js      → النافذة، القوائم، IPC (حفظ/تحميل/نسخ احتياطي/ملفات)
  preload.js   → جسر آمن بين Next.js و Electron (window.electronAPI)
lib/db.ts      → طبقة تخزين موحدة: localStorage (ويب) أو JSON في AppData (PC)
```

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| **التطبيق لا يفتح** | احذف `%APPDATA%/maktabi` وأعد التثبيت — أو شغّل كـ مسؤول |
| **البيانات اختفت** | تحقق من `AppData/Roaming/maktabi/maktabi-data.json` — استعد من نسخة |
| **تحذير SmartScreen** | More info → Run anyway |
| **المثبت يطلب صلاحيات** | وافق — يحتاج كتابة في Program Files |
| **الوثائق لا تُحفظ** | تأكد من صلاحيات `Documents/مكتبي - maktabi` |
