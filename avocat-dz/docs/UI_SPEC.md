## الشاشات

### Dashboard
- Welcome banner + date hijri? + quick add
- 4 KPIs: جلسات اليوم (أحمر لو اليوم)، آجال ≤10 أيام (نبض لو ≤3)، ملفات نشطة، أتعاب متبقية
- جلسات اليوم (قائمة) + chart إيرادات/مصاريف + آجال حرجة + pie أنواع القضايا + إجراءات سريعة + جدول أحدث الملفات

### Clients
- Grid cards + search + add form + expand لعرض قضايا العميل

### Cases
- Search + filter status chips + list (يسار) + detail Timeline (يمين sticky)
- Timeline: فتح الملف → جلسات → وثائق → استراتيجية

### Sessions
- Toggle list/calendar + add form + today highlight

### Deadlines
- Hero أحمر + filters + cards مع countdown + pulsing لو عاجل + checkbox إنجاز

### Documents
- Search + cat chips + table + upload form

### Templates
- List left + form middle + preview right with {{keys}} replace

... وكل صفحة Responsive + Dark mode + RTL.
